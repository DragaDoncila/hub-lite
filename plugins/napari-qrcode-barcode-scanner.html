A napari plugin that reads every QR code and barcode in an image layer. It outlines each code in a new shapes layer, labelled with its format and text, and keeps the engine's full report with it. The open-source engine runs inside napari's own Python: the image stays on your machine, and the layer's pixels are not changed.

The QR code scanner and the barcode scanner are QR Code AI's scanning pages in the browser. This plugin follows the same route as the QR code scanner napari guide and the barcode scanner napari guide. If a page is not online yet, this README is the reference.

To make a test image with a known value, use the QR code generator or the barcode generator. Open the exported image in napari, scan it and compare the label of the outline with the text you encoded.

Status

The plugin is on PyPI as napari-qrcode-barcode-scanner 0.1.0. The engine repository published that version from its tag napari-v0.1.0, after the owner's review, through PyPI trusted publishing: no token is stored. The files on PyPI are the sdist and the wheel that the tag's run built, checked with twine check --strict, installed in a new environment and tested on the sample in the three profiles. The plugin has also run in a napari window, from its dock widget, as the picture below shows.

napari's plugin manager and the napari hub read napari's plugin index, which is rebuilt once a day, so they can list the plugin a day or so after its PyPI release. What the listing shows, and where each value comes from, are in LISTING.md.

Install

Install the plugin from PyPI in the environment that runs napari:

python -m pip install napari-qrcode-barcode-scanner

Or, in napari, choose Plugins, Install/Uninstall Plugins, search for qrcode, install QR Code & Barcode Scanner and restart napari.

Its dependencies are numpy, magicgui and the engine wheel qrcode-barcode-scanner 0.11.0. As napari plugins do, it does not install napari or Qt: use the napari you have, or install the plugin with its all extra, python -m pip install "napari-qrcode-barcode-scanner[all]", to get both.

To try a change to the plugin, install the folder from a checkout of this repository instead: python -m pip install ./integrations/napari.

Use

Open an image, then choose Plugins, Scan QR codes and barcodes (QR Code & Barcode Scanner). Pick the image layer, a profile and a time budget, and press Run.

  • profile: fast (the default) suits uploads and gives a reduced quality score. frame gives no score. full searches deepest and gives the full score; artistic QR codes from a generator need it.
  • budget_ms: a time limit in milliseconds. 0, the default, means no limit.

The plugin adds a shapes layer named after the image, such as sample codes. A QR code or another matrix code is outlined by its four corners. A barcode is drawn as the line the reader scanned across it. Each shape is labelled with its format and text, and the full report is in the layer's metadata, under qrcode_barcode_scanner. A notification sums up what was read. A new scan of the same image replaces that layer; a scan that finds nothing removes it.

From a script, scan_layer returns the same result as napari layer data:

from napari_qrcode_barcode_scanner import scan_layer

data, meta, kind = scan_layer(viewer.layers["sample"], profile="full", budget_ms=0)
print([text for text in meta["features"]["text"]])

Limits

  • It reads 2D images: grey, RGB or RGBA. A stack or a volume is refused with a way out: split the stack with Layers, Split Stack, or project it first. A multiscale image is read at its full resolution.
  • The pixels pass through the layer's contrast limits, as napari shows them. The layer's data is only read.
  • An image wider or taller than 10,000 pixels, or above 64 million pixels, is refused with the engine's QRS- code.
  • The scan runs while napari waits. A full scan of a large image can take seconds: set a budget for those.

Develop

The tests call the widget function on napari's own layer classes and its viewer model, the model behind the window:

python -m venv .venv
.venv/bin/python -m pip install ./integrations/napari -r integrations/napari/tests/requirements.txt
.venv/bin/python -m pytest integrations/napari/tests

They scan the sample in the three profiles, and grey, float, 16-bit, offset and RGBA layers. They check that the pixels reach the engine unchanged, that the image layer is untouched, that a new scan replaces the codes layer, and that stacks, bad options and refused sizes fail clearly. They also check the manifest as napari discovers it and the form magicgui builds. The workflow integration-python-hosts of the engine repository runs them on the built wheel, in a new environment. The same workflow opens a napari window on a virtual display, with PyQt6, adds the plugin's widget, runs a full scan of the sample and checks that both codes are outlined. It keeps a picture of that window: tests/capture_window.py takes it, and media/napari-window.png is the one above.

How it works

The plugin reads the layer's 2D plane, maps it through its contrast limits to RGBA pixels and passes them to the engine, which runs in napari's Python process. Each scan gives one report.

What it returns

The picture is a recorded scan of the sample image, which holds a QR code and a Code 128 barcode. Both come back in one report, each with its format, its exact text and the place where the engine measured it: https://qrc-ai.com/76xMa and STOCK-4827.

The plugin returns a shapes layer: one shape per place the engine measured a code, with the code's text and symbology as features. The layer has the image's scale, translation, rotation, shear and affine transform, so the outlines sit on the codes.

The report itself is described field by field in the report reference. An empty list of detections means the image holds no code the engine could read. A refused file is an error with a QRS- code instead, listed in the error codes.

What it reads

Family Formats
QR QR Code, Micro QR, rectangular Micro QR (rMQR)
Matrix and stacked Data Matrix, Aztec, PDF417, MaxiCode
Retail EAN-13, EAN-8, UPC-A, UPC-E
Other linear Code 128, Code 39, Code 93, Codabar, ITF, GS1 DataBar, GS1 DataBar Expanded, Telepen

The plugin reads what the engine reads. Codes of different formats in one image come back in one report. The engine's supported formats section states the known limits.

Command line qrscan One command, one JSON report

The Rust, Node.js, browser and Python packages hold the engine. The Go and PHP packages hold no decoder: each one starts qrscan and hands you its report.
